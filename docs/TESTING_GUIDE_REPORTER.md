# Reporter Testing Guide (10–15 minutes, fictional data)

Use the fictional demo (Help → Fictional demo) or invent details; do not
enter real personal information.

## Tasks
1. Open the app → choose Reporter workspace (or continue as reporter).
2. **Report wildlife**: Report wildlife → an injured bird beside a road.
   - When found: "30 minutes ago".
   - Animal: "Not sure" type is fine; describe it ("small brown bird").
   - Location: type a description (no GPS needed).
   - Add one photo if you have a safe test image.
   - Contacts: skip.
   - Review: choose the private share profile → Create.
3. **Verify the timeline**: open the report → Timeline shows "Incident
   created" and "Photo added".
4. **Update the report**: Update report → "The bird moved under a hedge" →
   save → verify the timeline grew (history is never overwritten).
5. **Check statuses**: what does "Reported" mean? (Help → Statuses.)
6. **My reports**: use search (`/`) and the status filters; find your report.
7. **Export**: open the report → Export → Shareable preview → confirm your
   phone/email are redacted and coordinates excluded.
8. **Backup**: Settings → Storage & backups → Create backup. Note where the
   file went. Check "Storage health" numbers change.
9. **Leaderboard**: back on Home, find the Reporter leaderboard card —
   confirm your count increased and your level/milestone is shown.

## Feedback questions (short — answer in any words you like)
- What confused you?
- What did you expect to happen that did not?
- What did you NOT trust?
- What took too long?
- What would you actually use this for?
