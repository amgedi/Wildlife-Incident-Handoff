# 15-minute tester quickstart

Thanks for trying Wildlife Incident Handoff. This release candidate is ready for external testing, but please use fictional data first.

## Goal

Complete one realistic incident flow without needing help from the project owner.

## Before you start

- Download `v0.3.0-rc.2` from GitHub Releases.
- Use the installer for the normal Windows experience, or the portable build if you prefer not to install it.
- Do not use real sensitive wildlife coordinates, private contact details, or real case records during RC testing.

## The 15-minute flow

1. Launch the app and enter Test View or otherwise use fictional information.
2. Create one made-up wildlife incident.
3. Leave at least one field genuinely unknown instead of guessing.
4. Add or review location context.
5. Add a timeline update or correction.
6. Find the incident again from the workspace or map.
7. Record a handoff or responsibility change.
8. Create or inspect a shareable/exported handoff record.
9. Resize the app and confirm the main navigation remains usable.
10. Close and reopen the app, then confirm the fictional incident is still available.

## What to report

The most useful feedback is concrete friction:

- something you expected to click but could not find
- wording that made you stop and think
- a screen where you did not know what to do next
- an action that behaved differently from what you expected
- missing information you would need in a real workflow
- any crash, freeze, overlap, unreadable text, or broken layout
- anything that would make you avoid using the app again

You do not need technical language. A report such as “I expected the map row to open the incident but it only selected it” is useful.

## Five questions to answer at the end

1. Could you install and launch it without help?
2. Could you create and find an incident again?
3. Was it clear when information could stay unknown?
4. Could you understand and complete a handoff?
5. What was the single most confusing part?

That is enough for a useful first test.
