# Wildlife Incident Handoff demo

A short public demo is stored directly in this repository:

[▶ Watch the Wildlife Incident Handoff demo](./wildlife-incident-handoff-demo.mp4)

It introduces the problem Wildlife Incident Handoff is trying to solve, the report-to-handoff flow, the treatment of unknown information, core workspace features, and the RC testing path.

## Suggested uses

- include it in direct tester outreach
- share it with wildlife-adjacent communities before asking them to install the RC
- use it as a lightweight orientation link for people who want to understand the project before reading the full README

The video is supplemental. The GitHub README, tester guide, known limitations, and release notes remain the source of truth for the current RC.
