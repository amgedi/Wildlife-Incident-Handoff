# Updater key setup (Tauri update signing)

## What exists

A dedicated Tauri updater **minisign keypair** was generated on the owner's
machine on 2026-10-05 and stored OUTSIDE the repository:

- Private key: `C:\Users\jiggy\<user>\.tauri\wildlife-incident-handoff.key`
  (i.e. `%USERPROFILE%\.tauri\wildlife-incident-handoff.key`)
- Password file: `%USERPROFILE%\.tauri\wildlife-incident-handoff.key.password`
- Public key: embedded in `src-tauri/tauri.conf.json` under `plugins.updater.pubkey`
  (public material — safe to commit)

**Losing the private key or its password means installed clients will refuse
future signed updates.** Back up both files securely. They must NEVER be
committed, logged, screenshotted, or pasted into issues.

## The two different kinds of signing

1. **Tauri update signing** (minisign): verifies that an update package was
   produced by this project. Configured and working; independent of
   certificate authorities.
2. **Windows code signing** (Authenticode): establishes publisher identity
   with SmartScreen. Still a pending item — the installer/EXE remain unsigned
   until a certificate is purchased. This does NOT block Tauri update signing.

## GitHub Actions secrets (required by .github/workflows/release.yml)

Set in the repository: Settings → Secrets and variables → Actions:

- `TAURI_SIGNING_PRIVATE_KEY` — the full contents of the private key file
- `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` — the contents of the `.password` file

Never commit their values anywhere.

## Update endpoints (channel architecture)

- Tester channel (RC users): `…/releases/latest/download/tester.json`
- Stable channel: `…/releases/latest/download/latest.json`

Both are served from GitHub Releases of `amgedi/Wildlife-Incident-Handoff`.
The release workflow uploads the `.exe` + `.sig` (and NSIS `.zip` updater
artifact) generated by `tauri build` with `createUpdaterArtifacts: true`,
plus the channel JSON manifests. Until the repository is published, update
checks report "service unavailable" honestly — nothing fakes success.
